# Witcher LARP Core Engine

Рабочий прототип движка для 10-часовой LARP-игры во вселенной "Ведьмака".

## Что внутри

- Подробный ruleset: [docs/core-engine-v1.2.md](docs/core-engine-v1.2.md)
- Offline-first web/PWA-прототип без внешних зависимостей.
- Карта владений, лорды, ведьмаки, чародейки, PvE-проверки, эскроу-заказы, рынок, PvP-вызовы и черновой web-бой лордов.

## Как запустить

Открой `index.html` напрямую в браузере или запусти локальный сервер:

```powershell
python -m http.server 8080
```

После этого открой:

```text
http://localhost:8080
```

Данные сохраняются в `localStorage`. Кнопка сброса есть в верхней панели приложения.
